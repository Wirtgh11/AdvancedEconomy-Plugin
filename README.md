# AdvancedEconomy-Plugin 💰

Плагин виртуальной экономики для серверов Minecraft (Spigot / Paper).

## 🚀 Особенности
- **SQLite баз данных:** Автоматическое сохранение баланса игроков.
- **Интерактивное GUI:** Просмотр баланса через удобный интерфейс сундука.
- **Команда /bank:** Быстрый доступ к банковскому счету.

## 🛠 Технологии
- Java 17
- Spigot API (1.20.1)
- SQLite & JDBC

## 📋 Установка
1. Скачайте `.jar` файл плагина.
2. Поместите его в папку `plugins/` вашего сервера Spigot/Paper.
3. Перезапустите сервер.
